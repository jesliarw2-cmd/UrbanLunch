# Urban.Lunch — Pruebas de aplicación móvil (Android)

Proyecto del Sprint 6 del programa QA Engineer de TripleTen. Pruebas manuales
de la primera versión para Android de la aplicación Urban.Lunch, que permite
pedir comida de distintos restaurantes de la ciudad y recogerla en un punto
de entrega.

## Descripción del proyecto

El objetivo fue analizar los requisitos de la aplicación móvil Urban.Lunch,
diseñar una lista de comprobación para una parte de los requisitos marcados
como prioritarios, ejecutar las pruebas en el emulador de Android Studio y
documentar los errores encontrados como tickets en Jira.

## Alcance de las pruebas

Se ejecutaron 33 comprobaciones cubriendo todo el flujo de la aplicación:
selección de restaurante, elección de productos, confirmación del pedido y
seguimiento en el mapa hasta el punto de recogida. Se reportaron 4 bugs con
sus respectivos tickets en Jira.

## Entorno de pruebas

- Emulador de Android Studio (Pixel 5)
- Jira para el reporte de errores

## Notas

Este proyecto fue revisado con el estado "Aprobado con observaciones". Los
archivos de este repositorio corresponden a la versión final corregida tras
la retroalimentación recibida.
